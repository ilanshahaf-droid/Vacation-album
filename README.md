# אלבום החופשות שלנו

אלבום זיכרונות מכל החופשות: מיקום, תאריכים, מקומות, מסעדות, אתרים, הצגות/מופעים/מוזיאונים/אטרקציות ותמונות.

## הקמה (פעם אחת)
1. ב-Supabase (פרויקט Down-to-the-bone): SQL Editor ← להריץ את `schema.sql`.
2. ב-Supabase: Authentication ← URL Configuration ← להוסיף ל-Redirect URLs את
   `https://ilanshahaf-droid.github.io/Vacation-album/`
3. ב-GitHub: Settings ← Pages ← Branch: `main` / root.
4. להיכנס מהטלפון (Google או אימייל) ולהוסיף למסך הבית.

## הערות
- התמונות מוקטנות לפני ההעלאה (עד 1600 פיקסלים, כ-300KB) ונשמרות בתיקייה פרטית `album-photos`.
- תמונות HEIC עולות רק בדפדפנים שיודעים לפתוח אותן (באייפון בדרך כלל מומרות אוטומטית ל-JPEG).

## עדכון גרסה
אחרי שינוי בקבצים, להעלות את המספר ב-`CACHE` בקובץ `sw.js` (למשל album-v2).
