# אלבום החופשות שלנו

אלבום זיכרונות מכל החופשות: מיקום, תאריכים, מקומות, מסעדות, אתרים, הצגות/מופעים/מוזיאונים/אטרקציות ותמונות.

## הקמה (פעם אחת)
1. ב-Supabase (פרויקט Down-to-the-bone): SQL Editor ← להריץ את `schema.sql`, ואחריו את `update-sharing.sql` ו-`update-files.sql`.
2. ב-Supabase: Authentication ← URL Configuration ← להוסיף ל-Redirect URLs את
   `https://ilanshahaf-droid.github.io/Vacation-album/`
3. ב-GitHub: Settings ← Pages ← Branch: `main` / root.
4. להיכנס מהטלפון (Google או אימייל) ולהוסיף למסך הבית.

## שיתוף
כפתור "👥 שיתוף" למעלה ← להוסיף כתובת Gmail. מי שנוסף נכנס עם Google באותה כתובת,
ורואה את האלבום המשותף (צפייה, הוספה ועריכה של חופשות ותמונות). אם יש לו גם אלבום משלו – בוחרים ביניהם ברשימה למעלה.

## גוגל תמונות
לכל חופשה אפשר לשמור קישור לאלבום משותף בגוגל תמונות (בעריכת הפרטים), והוא נפתח בכפתור בדף החופשה.
Google לא מאפשרת לאפליקציות חיצוניות להציג תמונות מהספרייה שלך באופן קבוע (מאז מרץ 2025), ולכן התמונות שמוצגות באלבום עצמו נשמרות ב-Supabase.

## הערות
- התמונות מוקטנות לפני ההעלאה (עד 1600 פיקסלים, כ-300KB) ונשמרות בתיקייה פרטית `album-photos`.
- תמונות HEIC עולות רק בדפדפנים שיודעים לפתוח אותן (באייפון בדרך כלל מומרות אוטומטית ל-JPEG).

## עדכון גרסה
אחרי שינוי בקבצים, להעלות את המספר ב-`CACHE` בקובץ `sw.js` (למשל album-v2).
